# Movie Tracker

Приложение для отслеживания фильмов, которые хочется посмотреть или уже удалось посмотреть.

## Как запустить

```
npm install
npm run dev
```

После этого открыть http://localhost:5173

## Что умеет

- хранить личную коллекцию фильмов
- добавлять, редактировать и удалять записи
- отмечать просмотренные фильмы
- искать по названию и фильтровать по жанру
- сохранять список в `localStorage`
- получать подборку фильмов из внешнего API
- переходить между страницами через `React Router`

## Страницы

- `/` — личная коллекция
- `/discover` — подборки фильмов из API

## Использованные технологии

- React
- React Router
- Vite
- Fetch API
- LocalStorage
