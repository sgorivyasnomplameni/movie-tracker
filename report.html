Отчет по мини-проекту Movie Tracker

Movie Tracker — это React-приложение для ведения личной коллекции фильмов. Пользователь может добавлять фильмы вручную, редактировать их, отмечать просмотренные, искать по названию и фильтровать по жанру. Также в приложении есть отдельная страница с подборкой фильмов, которые загружаются из внешнего API и могут быть добавлены в общую коллекцию.

Структура компонентов

  • App.jsx — общее состояние и маршрутизация.
  • components/Layout.jsx — шапка и навигация.
  • pages/MyMoviesPage.jsx — личная коллекция.
  • pages/DiscoverPage.jsx — страница с API.
  • components/MovieList.jsx — список фильмов.
  • components/MovieCard.jsx — карточка фильма.
  • components/MovieForm.jsx — форма добавления и редактирования.
  • components/SearchBar.jsx — поиск.
  • components/RecommendationCard.jsx — карточка фильма из API.

Использование useState

  • В App.jsx хранится общий массив movies.
  • В MyMoviesPage.jsx хранятся searchText, filterGenre, showForm, editMovie.
  • В MovieForm.jsx хранится состояние формы form.
  • В DiscoverPage.jsx хранятся recommendations, loading, error.

Использование useEffect

  • В App.jsx при изменении массива movies данные сохраняются в localStorage.
  • В DiscoverPage.jsx при открытии страницы выполняется fetch к API и данные отображаются в интерфейсе.

Использование props

  • App.jsx передает массив movies и функции в страницы.
  • MyMoviesPage.jsx передает данные в MovieList, MovieForm, SearchBar.
  • MovieList.jsx передает отдельный фильм в MovieCard.
  • DiscoverPage.jsx передает фильм в RecommendationCard.

Работа с API

Для загрузки данных используется fetch к API:

https://ghibliapi.vercel.app/films

  • После загрузки приложение берет несколько фильмов из ответа.
  • Для каждого фильма формируется объект с нужными полями для интерфейса.
  • Пользователь может добавить фильм из внешней подборки в личную коллекцию.

Routing

  • В main.jsx приложение обернуто в BrowserRouter.
  • В App.jsx настроены маршруты / и /discover.
  • Переход между страницами выполняется через NavLink.

Основная логика приложения

  • Пользователь может добавлять, редактировать и удалять фильмы.
  • У каждого фильма можно переключать статус просмотра.
  • Список фильмов сохраняется в localStorage.
  • На странице API можно получать внешние данные и добавлять их в общий список.

Запуск проекта

npm install

npm run dev
